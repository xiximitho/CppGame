# Créditos da arte em `assets/tibia_like/`

As folhas de sprite desta pasta são do **OpenTibia Sprite Pack**, de **peonso**:

- Origem: <https://github.com/peonso/opentibia_sprite_pack>
- Licença: **CC BY 4.0** (<https://creativecommons.org/licenses/by/4.0/>)

Arquivos:

| Arquivo | Conteúdo |
|---|---|
| `otsp_creatures_03.png` | criaturas, 4 direções × 3 frames por bloco |
| `otsp_equipment_01.png` | armas, armaduras, escudos, poções (estático) |

**CC BY exige atribuição**, inclusive na arte derivada — os recortes que o
`tools/import_otsp.py` cola no `assets/tilesets/atlas.png` são obra derivada, então o
crédito acima cobre o atlas também. Se o jogo ganhar uma tela de créditos, é este
texto que vai nela.

Detalhes técnicos das folhas (grade, color key, ordem das direções) estão em
`docs/animation.md`; aqui é só a procedência.
